# Examples

Command recipes for every group of `2bec`, with the scopes each needs and
the API behaviours worth knowing. `2bec <group> --help` is the reference;
these pages show the commands together, the way a task uses them.

- [auth.md](auth.md): browser, device and API-key login; the OS keyring.
- [configuration.md](configuration.md): precedence, profiles, the `config` command, completions and manual pages, upgrading.
- [scripting.md](scripting.md): output modes, exit codes in bash, CI gates, cron exports, failure watches.
- [runs.md](runs.md): list, inspect, download, comment, tag and trigger runs.
- [scenarios.md](scenarios.md): the catalog, a scenario's figures and documents, settings, thresholds, availability rules.
- [monitoring.md](monitoring.md): metrics, alerts, neutralizations, incidents, interruptions, planning.
- [administration.md](administration.md): variables, tags and badges, users and profiles, audit, comments, tickets.
- [reports-and-webhooks.md](reports-and-webhooks.md): saved reports, schedules, deliveries, webhooks.
